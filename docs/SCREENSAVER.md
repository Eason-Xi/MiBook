# 自选屏保：横屏、编辑与恢复

先完成 [安装与配对](SETUP.md) 和 [Root](ROOT.md)。Mac 运行 macOS 15 或更高；阅读器需要允许「AI 用量」使用 Root。Magisk 31.1 从 Superuser 页面事先授权，不依赖调用时弹窗。

## 打开编辑器

```sh
bash scripts/build-mac-screensaver.sh
open dist/小米屏保.app
```

1. 点击“选择图片”，选择 JPG、PNG、HEIC 等系统可解码图片。横屏原图自动选择横屏画布，也能手动切换。
2. 竖屏画布 1404 × 1872；横屏画布 1872 × 1404。画布会随选项切换。
3. 选择“铺满裁切”或“完整留白”。拖动预览调整位置，或使用左右／上下滑块。
4. 100%～300% 缩放；每次顺时针旋转 90°；“复位构图”恢复居中、100% 和铺满模式，保留画布方向与灰度选择。
5. 按需要保留彩色编辑预览或转为黑白灰度。实体墨水屏最终显示灰阶。
6. 可先“导出”得到对应画布方向的 PNG。编辑原图副本和参数自动保存在本机，不改写你选择的原文件。

移动范围由画面实际溢出／留白范围决定。铺满模式保持覆盖画布；如果图片与画布比例相同，先放大再移动才能改变裁切位置。

## 应用到阅读器

唤醒阅读器，打开「AI 用量」，保持 Mac 与阅读器在同一 Wi-Fi。Mac 显示连接且 Root 就绪后，点击“应用并重启阅读器”。

Mac 服务生成只含图片、无代码和权限的资源覆盖 APK，打入可停用的 Magisk 模块 `mibook_screensaver`。阅读器核对传输摘要、模块白名单和 APK 属性，准备模块后自动重启一次。重启后验证系统启用状态、挂载 APK 摘要，以及全部八张屏保资源的解码尺寸和像素。

如果回执长时间停留在等待重启，请在开机后打开「AI 用量」补发校验。资源校验通过后，按实体电源键观察实际屏幕；不要只凭传输完成就认定图片已经显示。

横屏构图在发送时逐像素顺时针旋转为固件使用的 1404 × 1872 物理画布，没有再按竖屏比例裁切。横握阅读器观看横向图片。系统另外绘制的日期位置和方向仍由固件决定；Mac 预览只显示图片。

## 为什么每次换图都要重启

本机固件的 `showCustomWallPaper()` 实现直接返回 false，自定义图片 setter 不会进入真正显示分支。因此目前覆盖系统原有屏保资源，依靠 Magisk 在启动时挂载、系统重新加载资源。直接删除重启步骤会继续使用旧的挂载／缓存资源。

当前没有实现免重启的动态屏保服务；不要把“接口调用成功”当作免重启显示已经实现。适配证据见 [固件记录](../macos/SCREENSAVER-FIRMWARE.md)。

## 恢复原屏保

Mac 点击“恢复系统原屏保（重启）”，或在 Magisk 模块页面停用 MiBook Screensaver 后重启。模块只覆盖 `/vendor/overlay/MiBookScreensaver.apk`，没有直接改写厂商原始 `framework-res.apk`。

恢复原屏保与撤回 Root 是两件事。撤回 Root 请先确认原屏保已恢复，再按 Root 文档使用你自己备份的原始 boot。

## 本地验证

```sh
bash scripts/test-mac-screensaver.sh
```

测试覆盖横／竖屏尺寸、留白／铺满、灰度、移动、缩放、旋转、横屏物理编码，以及编译后八张实际 PNG 资源是否保持原数据。测试只生成 `build/` 下的本地产物，不连接或重启阅读器。
